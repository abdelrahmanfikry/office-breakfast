# فطار المكتب — Office Breakfast

موقع بسيط لطلبات الفطار في الشركة: كل واحد يسجّل طلبه، الكل يشوف طلبات بعض (من غير ما حد يعدّل طلب غيره)، التجميع للمطعم بضغطة، والحساب والتحويلات بين الناس.

## المزايا
- **الطلبيات:** طلبية لكل مرة (فطار/غدا…) — مين بيدفع، رسوم توصيل تتقسم بالتساوي، آخر معاد للطلب، وتاريخ (النهارده أو امبارح).
- **الطلب:** كل واحد يضيف أصنافه — من المنيو بضغطة أو يكتب — مع ملاحظة، وأزرار + / − للعدد.
- **أزرار سريعة:** طلبية النهارده · طلبية امبارح · كرر آخر طلبية · كرر طلبي اللي فات · اعمل زيها النهارده.
- **التجميع:** ملخّص الأصناف بالعدد جاهز للنسخ أو الإرسال واتساب.
- **ملاحظات:** على كل طلبية.
- **الحساب:** مين ليه ومين عليه مع كل شخص + رصيد الكل. بيتحسب من الطلبيات المقفولة بس.
- **التحويلات:** اللي حوّل يسجّل، واللي استلم يأكد «وصلني» — ومش بيتحسب غير بعد التأكيد.
- **المنيوهات:** المطاعم وأسعارها مرة واحدة.
- **التنظيف (للأدمن):** مسح البيانات القديمة علشان الليمت المجاني، والأرصدة بتترحّل قبل المسح فالحساب ما بيضيعش.

## التشغيل
- **الموقع:** GitHub Pages من فولدر `docs/`.
- **البيانات:** Firebase project `office-breakfast-c9338` — Authentication (Email/Password) + Firestore.
- **قواعد الأمان:** `firestore.rules` — أي تعديل فيها يتنشر من Firebase Console ← Firestore ← Rules (أو `firebase deploy --only firestore:rules`).
- **أول مرة:** أول واحد يدخل يروح «حسابي» ويضغط «خليني الأدمن».
